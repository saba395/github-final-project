# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for everyone participating in this project.

## Expected Behavior

Participants are expected to be respectful, constructive, and considerate of others.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, and inappropriate behavior are not tolerated.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.
